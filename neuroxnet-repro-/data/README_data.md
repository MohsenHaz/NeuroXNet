# Data layout

* `splits/cq500_split_seed42.csv`  columns `study_id,split` with split in {train,val,test}; 344/74/73 studies, patient level, seed 42, stratified on the four-level label.
* `splits/cq500_cv5_folds.csv`     columns `study_id,fold` with fold in {1..5}; fold sizes 99,98,98,99,97, stratified on the four-level label.
* `labels/cq500_severity_labels.csv` columns `study_id,reader1,reader2,final_label,evans_index,temporal_horn_dilation,periventricular_lucency,adjudicated_flag`.
  Labels 0 normal, 1 mild, 2 moderate, 3 severe. `reader1`/`reader2` are the independent pre-adjudication labels from which the weighted kappa is computed; `final_label` is the consensus label.
* `labels/annotation_protocol.pdf`   the fixed protocol (Evans' index intervals, temporal horn and periventricular descriptors).
* `labels/gradcam_roi_subset_ids.csv` columns `study_id,cohort,class` for the 100 studies with consensus ventricular ROI masks; masks are stored as `data/roi_masks/<study_id>.npz` (key `mask`, shape S x 256 x 256).
* `external/external_predictions_deidentified.csv` NeuroXNet predictions on the external cohort, plus `vendor,slice_thickness_mm,age_group` columns for Table 11. No image data, no dates, no institution.
* `preprocessed/<study_id>.npy` is generated by `scripts/01_preprocess.py`: float16 array of shape 128 x 256 x 256 after windowing, selection, resizing and normalisation.

Both split files are generated once by `scripts/01_preprocess.py --make-splits` and committed; they must never be regenerated after training.
